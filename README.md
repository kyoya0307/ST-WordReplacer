# ST-WordReplacer

SillyTavern 独立前端扩展：分类词库、快捷改词、批量添加、保护词、替换预览和 JSON 备份。不需要酒馆助手，不需要构建或安装 npm 依赖。

## 安装

1. 在 SillyTavern 中打开「扩展」→「安装扩展」。
2. 填入 `https://github.com/kyoya0307/ST-WordReplacer` 并安装。
3. 刷新 ST 页面，在聊天输入区点「词库」，或在扩展设置中点「打开词库管理」。
4. **停用之前的「辱女词汇替换」酒馆助手脚本**，避免两个工具重复替换。

如果手动安装，把本仓库文件放入 `SillyTavern/data/<你的用户目录>/extensions/ST-WordReplacer/`；`manifest.json` 必须直接位于这个文件夹中。也可放在 `SillyTavern/public/scripts/extensions/third-party/ST-WordReplacer/` 供所有用户使用。刷新页面后加载。

## 快捷入口

- 聊天输入区的「词库」按钮。
- 快捷键 **Alt + Shift + W**，或在 ST 输入 `/wordlib`。
- 在聊天正文中选中不超过 200 字的文本，点击右下角「＋ 加入词库」，自动填入新增原词。

## 分类词库

原脚本的 124 条原词和替换值已完整迁入，分为「删除词」「整词替换」「单字替换（注意误替换）」；保留了原脚本特殊句式规则，提供独立开关。只修复原文件“巾帼不让须眉”一行缺失的引号，没有替你改动替换值。

可以新建、改名、开关、删除和调整分类顺序。每条词也能开关、直接修改。修改后会自动写入 ST 的扩展设置，随 ST 用户设置保存在服务器；升级扩展不会用默认词库覆盖你的设置。不会自动提交到 GitHub，也不会共享给其他 ST 用户。建议定期导出备份。

在「词库」页上方填写 **原词 → 替换词**，点击「添加 / 更新」。同分类中存在相同原词时更新该词；替换词留空表示删除原词。支持搜索、每页 80 条，便于较大词库编辑。

「批量添加到当前分类」支持每行一条：

```text
# 这是注释
老天爷 → 老天奶
母狗 →
原词 => 替换词
```

也支持制表符分隔；批量粘贴会去掉原词与替换词两端空格。需要匹配空格时，请用单条编辑。

## 匹配顺序

1. 保护词和代码块原样保留。
2. 如开启特殊句式，先处理原脚本的侮辱性组合。
3. 已启用分类中的已启用词条按**长词优先**匹配；相同原词由**靠后的分类**覆盖。同分类重复原词以靠后的词条为准。
4. 一次词库替换不会把结果再次送回词库匹配，例如 A→B、B→C，原文 A 只会变为 B。
5. 如开启特殊句式，再执行原脚本的其他上下文规则。

自定义词条是**纯文本**，不是正则表达式。`$&` 等内容也按普通替换文本处理。特殊句式规则在词库前后执行；如果你希望所有结果严格只受词库控制，关闭该开关。

默认自动处理 **AI 回复完成后的正文**。流式生成中暂不改字，完成后才替换。可另行开启「自己发出的消息」「编辑后的消息」。不监听输入框逐字输入，不干扰中文输入法。默认开启代码块保护。

**正文替换会保存到聊天文件，后续模型可见的历史也会改变。** 单字规则和上下文规则可能误伤名字、普通词语或链接；请在「预览与保护」测试、添加保护词，或关闭相关分类。不会自动扫描已有聊天、修改角色卡、世界书、推理区或未选中的 swipe 候选。切换已有 swipe 不会主动触发改写；新生成的 swipe 在完成时处理。

## 备份与历史消息

「备份与导入」可导出全部设置或单个分类。导入支持追加为新分类，或手动确认后覆盖全部设置；只接收本扩展的 JSON 数据，不执行 JS。其他格式词库可先整理为批量文本粘贴。

「历史消息」先预览当前聊天，再确认应用。默认仅处理 AI 正文，可选择同时处理自己的消息。应用前下载受影响消息的原文 JSON 备份，并提供本次页面会话中的撤销按钮。期间若切换聊天、修改消息或修改词库，必须重新预览。请确认浏览器允许下载备份。下载文件是**正文备份记录**，不是完整的 ST 聊天导入文件；需要完整聊天备份时请先使用 ST 自带的聊天导出。

自动替换的新消息可以通过 ST 消息编辑功能修改；编辑自动替换默认关闭，便于手动恢复。历史撤销只在当前页面和当前聊天有效；刷新或切换聊天后，请从下载的原文记录手动恢复。

## 快捷编程接口（可选）

扩展加载后提供 `window.STWordReplacer`，方便你从其他脚本或浏览器控制台管理词库。接口操作仍只保存到 ST 设置。

```js
STWordReplacer.open();
STWordReplacer.upsert({ category: '用词习惯', from: '原词', to: '新词' });
STWordReplacer.upsert({ category: '删除词', from: '想去掉的词', to: '' });
STWordReplacer.preview('只预览，不改聊天'); // { text, hits }
const backup = STWordReplacer.export(); // 返回副本
// STWordReplacer.import(backup); // 校验后覆盖当前设置
```

## 更新与开发

在 ST 扩展管理器中手动检查/更新本扩展，然后刷新页面。没有后台自动下载或外部脚本依赖。

开发测试：Node.js 20+，运行 `npm test`，无须 `npm install`。使用 ST 官方 `SillyTavern.getContext()` 获取设置、事件、正文更新和聊天保存接口。

参考：[ST 扩展开发文档](https://docs.sillytavern.app/for-contributors/writing-extensions/)、[ST release 源码](https://github.com/SillyTavern/SillyTavern/tree/release/public)。
