# 词汇快捷替换

SillyTavern 前端扩展，用于整理词汇、清理句子和保留指定内容。安装后从扩展设置或聊天输入区的魔法棒打开。

当前版本：**1.2.10 · 开发测试版**。

## 安装与更新

在 SillyTavern 的「扩展 → 安装扩展」中填写：

```
https://github.com/kyoya0307/ST-WordReplacer
```

安装完成后刷新页面。后续在「管理扩展」中更新，再刷新页面。

仓库根目录包含扩展入口，SillyTavern 直接克隆仓库加载。安装时使用运行 SillyTavern 那台设备的 Git 和网络；遇到网络错误，可检查该设备的代理、Git 配置和服务端日志。

## 从这里开始

主导航依次为五页：

| 页面 | 用途 |
| --- | --- |
| 词库 | 固定文字的替换与直接删除 |
| 条件规则 | 固定结构、关键词删句和标记内容 |
| 保护词 | 集中整理通用保护、内置正常用法和手动保护词 |
| 冲突检查 | 检查已启用内容中的不同处理结果 |
| 设置 | 作用范围、生效方式和数据工具 |

新安装提供空白分类。可以添加第一条词，也可以通过「设置 → 导入 / 导出」加载备份。

仓库只包含扩展代码和中性测试词库，不包含任何使用者的个人词库。`legacy.js` 中的内置语境模板是实现正常用法判断所必需的规则，不是可导入词表。

每次打开进入词库，保留上次查看的分类。电脑左侧选择分类；手机点击当前分类名称，打开可搜索的分类面板。

顶部提供全局搜索，可同时查找所有分类中的原词、替换词、规则名称、触发内容、附加条件和保护词。搜索结果显示内容类型、来源分类与启停状态，支持直接启停和定位编辑；停用条目也会出现在结果中。清空搜索后返回原页面。

## 词库

词库页顶部直接提供「原词 → 替换为」输入框。填写后点击「添加」或按回车，保存后输入框清空并定位到原词，方便连续录入：

- **替换为**：填写新的文字，例如 `单车 → 自行车`。
- **删除文字**：替换词留空，删除命中的固定文字，例如 `今天【待删】出发。 → 今天出发。`。

点击已有词条进入编辑。编辑框内保存后应用；各类开关、排序和保护词修改自动保存。

列表可选择每页 10 条或 15 条，默认每页 15 条。排列方式可选择「默认顺序」或「原词拼音顺序」，选择会保存并用于各分类的词条列表。拼音排序仅调整显示，替换执行沿用原来的分类与词条优先级；切回默认顺序即可查看原始排列。新增或编辑后会定位到该词条所在页。

批量添加每行一条，使用 `=` 分隔原词与替换词。也兼容 `＝`、`->`、`=>`、箭头和制表符：

```text
单车=自行车
【待删】=
```

普通词条按完整文字匹配。长词优先；相同原词以靠后的已启用分类为准。替换结果在本轮词库匹配中处理一次。

分类设置提供改名、上下排序和单类导出。批量选择后可复制、剪切、启停；切换目标分类后粘贴。剪切在成功粘贴后移除来源条目。粘贴预览提供新增、相同和冲突数量。

选择直接删除的词条，点击「移到条件规则」，可以设定删除范围并迁入规则分类。

## 分类开关

分类复选框汇总条目的实际状态：

- 勾选：全部启用。
- 横杠：部分启用，同时显示启用数量。
- 空框：全部停用。

勾选整个分类会启用所有条目；取消勾选会停用所有条目。在停用分类中单独开启一条，该条立即生效，分类显示部分启用。

顶部总开关用于暂停全部处理，并保留分类选择。

单条或分类停用后，该处的规则停止参与处理。相同原词也可能存在于其他已启用分类，全局搜索可查看这些来源。显示开关与模型输入开关分别控制聊天中的呈现和发送给模型的副本。

## 小说阅读器兼容

安装 QwQ361/ST-Novel-Reader 时，词汇快捷替换会自动接入其公开的章节接口。普通章节、连续滚动、翻页与消息版本切换使用当前已启用的替换、删除和保护规则，沿用「影响显示」以及 AI / 用户消息范围。

兼容代码全部位于本插件，阅读器无需修改。处理对象为章节的显示副本；原始消息、各版本与聊天文件保留原文。修改规则后，已打开的正文会更新，翻页模式重新计算页数。

## 条件规则

条件规则页左侧按固定触发模板组织内容。选择模板后点击「添加触发内容」，填写触发词、固定结构或起止标记，右侧或下方即时展示测试结果。内容本身作为标题，备注名称可以按需填写。

| 触发模板 | 固定处理与示例 |
| --- | --- |
| 关键词删句 | 任意词或完整短语出现时删除所在分句，如 `【待删】` |
| 共同出现删句 | 同一句包含 `声音` 和 `平` 时，删除它们所在的连续分句，顺序任意 |
| 固定结构清理 | `极` ＋ `1 个汉字` ＋ `的`，删除匹配文字 |
| 自我纠错清理 | 关键词后出现破折号与“不对”，清理误写及重复解释，接回后续正文 |
| 标记内容清理 | 删除 `[示例开始]` 与 `[示例结束]` 之间的内容，包含标记 |

「更多模板」提供完整句子删除、匹配词段删除和去掉固定开头。去掉固定开头可将 `极轻的` 变为 `轻的`，保留中间文字和结尾。每个标准模板的匹配类型、触发方式和处理范围固定，编辑时集中填写触发内容与可选保留条件。

同一模板汇总所有来源分类中符合该处理方式的内容。已有分类、排序、保护范围和启停状态继续保留；自定义边界、指定替换等内容集中在「其他已有规则」中编辑。「分类与批量整理」提供原有分类、排序、复制、剪切和批量管理。

固定结构可以设置中间汉字的最少、最多字数。例如：

```text
处理前：响起极轻的脚步声，随后传来极重的撞击声。
处理后：响起脚步声，随后传来撞击声。
```

起止标记支持跨行，逐段匹配成对标记。示例用于填入编辑器，保存后启用。

### 删除范围

- **匹配文字**：只处理匹配到的片段。
- **所在分句**：按逗号分隔，删除命中分句并整理相邻标点。
- **完整句子**：从句首处理到句末，包括句末标点。

关键词共同出现时，分句范围覆盖这些关键词所在的连续分句。句号、问号、感叹号、分号、省略号及换行构成句子边界。已有的分类默认范围继续作用于沿用它的旧规则；通过标准模板添加的内容使用模板自身的固定范围。

| 原文 | 删除分句后的结果 |
| --- | --- |
| `她点头，【待删】这句是草稿。` | `她点头。` |
| `她点头，【待删】这句是草稿，然后坐下。` | `她点头，然后坐下。` |

卡片直接显示触发词、固定结构、起止标记和补充条件。语境模板直接显示其匹配内容，已有的固定替换规则显示实际替换文字。点击「编辑触发 / 测试」修改内容并试用。全局搜索支持备注名称及具体触发内容。

共同出现规则可在补充条件中设置「最多涉及几个分句」和「按关键词填写顺序匹配」。例如依次填写 `慢点`、`没人和你抢`，分句数设为 `2` 并开启顺序匹配，会清理相邻的两个分句；中间夹有其他分句时保留。`0` 表示分句数不限。

自我纠错清理按填写的关键词识别纠错过程。每行一词，任意一项即可触发；默认纠错提示词为“不对”，也可在编辑器中调整。支持中文破折号及双短横线。模板在当前句内清理误写分句与反复提及该关键词的解释分句，接回后续正文，例如 `她的翅膀——不对，她没有翅膀，她的手臂伸向窗外。` 变为 `她的手臂伸向窗外。`。原有保护词、代码块保护和补充条件继续适用。

分句和整句清理会检查成对引号中的剩余正文。对白全部删空时，同时清理可识别的简短说话引导语，支持引导语与对白分行；对白仍有正文时，保留引导语和引号。例如 `她说：“【待删】。”她转身。` 清理后为 `她转身。`；`她说：“【待删】，明天见。”` 清理后为 `她说：“明天见。”`。逗号分隔的独立动作保留，例如 `她推开门，低声说：“【待删】。”` 清理后为 `她推开门。`。

多个删除范围合并后整理标点；重叠替换采用最长匹配，同长度采用靠后的规则。句段和固定结构先处理；语境模板沿用其词库前、词库后的执行位置。

### 补充匹配条件

编辑器中的「补充匹配条件」可逐项添加前接、后接、伴随词和保留条件，每项配有成对示例：

| 条件 | 示例：苹果 → 水果 |
| --- | --- |
| 前接“红”时处理 | 红苹果 → 红水果；青苹果保持原样 |
| 后接“汁”时处理 | 苹果汁 → 水果汁；苹果树保持原样 |
| 后接“公司”时保留 | 苹果公司保持原样；桌上有苹果 → 桌上有水果 |
| 同句含“品牌”时保留 | 这个品牌叫苹果。保持原样；桌上有苹果。可以命中 |

文字边界可选择任意位置、两侧为非汉字边界，或两侧为标点、空白及文本边缘。例如“草稿。”满足独立边界；“草稿纸”与其他汉字相连。

伴随词和保留词可在同一句或同一逗号分句内判断。共同出现规则可设置关键词的最大间隔，0 表示不限。试用结果会显示处理次数和保留原因，帮助核对每项条件。

### 语境模板与旧规则

旧版 7 类、13 个匹配步骤整理为普通规则卡片，归入「语境规则」分类。分类与条目开关、固定替换文字和词库前后执行位置继续保留。可从「保护词 → 内置保护规则」查看这些模板，点击「添加触发内容」载入模板。

语境编辑器提供「匹配方式与执行顺序」，说明已发现的匹配问题。亲属类模板按完整称谓、后接内容及亲属动作保留正常表达；独立表达使用完整汉字边界；名称类模板提供汉字连写保护。这些策略可逐条选择，补充条件继续适用。

各条亲属规则的编辑器中提供「本规则的正常用法保留条件」，可调整前接与后接文字。旧共享表中的自定义内容随规则迁入，保存后各条规则独立编辑。旧备份中的自定义边界规则继续沿用其起止标点。

## 保护词

此页分为「手动保护词」和「内置保护规则」。通用保护按书名号和代码标记识别范围；内置规则提供完整词语、亲属表达、数字与固定名称等正常用法保护。卡片展示处理对象、修改前后对照和正常用法检查。示例由当前单条规则实际计算，点击可载入编辑器试用。顶部开关控制下方全部规则，卡片开关控制当前一条。

创建保护词分类，每行一条批量添加，或逐条录入。默认保护范围为全部处理，也可选择指定词库、规则分类或内置语境处理。

例如将 `晨光计划` 加入保护词，该短语保持原样。普通替换遇到保护词时保留该次匹配；分句和整句清理只保留保护词本身，其余命中内容继续清理。条件规则的「进阶：保护优先级」可选择保护优先或清理优先。

## 测试与冲突检查

词库、条件规则和保护词页顶部提供「测试效果」。「冲突检查」位于主导航中，在保护词与设置之间；「导入 / 导出」集中放在设置中。

测试可使用全部已启用内容或当前分类，可载入最近 AI 回复。匹配位置使用划线标记，「命中检查」可按删除、替换、保护、条件未满足和优先级覆盖筛选，也可选择具体规则。点击记录，高亮原文中的对应位置，并显示来源、处理原因、保留依据和本次结果；「定位这条规则」进入编辑，保护拦截记录还可跳转到相应保护词。连续处理产生的位置变化会映射回输入原文。在测试中选中文字或手动填写，可以直接加入全局保护并重新测试。

冲突检查仅列出已启用内容中的不同处理结果。相同原词对应不同结果、相同条件采用不同处理时，显示来源并提供定位入口。完全相同的重复项作为普通重复保留。

## 生效与保存

默认作用于 AI 输出，影响显示和模型输入，编辑后生效，并保护代码块。设置中可分别调整。

自动处理保留聊天文件原文，显示内容和模型请求副本使用处理结果。原生格式化接口在 Markdown 前处理普通消息；HTML 消息和兼容显示就地更新可读正文，保留 HTML 标签、交互元素和 iframe。调整开关或词条后，可读正文按当前配置更新；停用时恢复原文，交互窗口继续运行。代码保护保持代码节点原样，iframe 内部独立运行。

配置保存在当前 ST 用户的扩展设置中。更新扩展后继续使用已保存的配置。

### 流式显示

普通原生格式化消息随酒馆刷新应用规则。富文本和旧版兼容路径监听当前流式消息，约 40 毫秒合并一次显示更新，直接修改可读文字节点。持续输出期间也会更新，停止或结束生成时处理最后一块内容。原始消息、版本正文、代码和交互 iframe 保持原有处理方式。

每次按当前已到达的内容重新判断。关键词补全后即可命中；后文出现保留条件时可恢复原词。例如“我靠”后继续输出“近”，会按“我靠近”的正常用法保留。依赖完整短语或后文的条件，在相关文字到达后生效，过程中可能出现短暂的先替换后恢复。

## 导入、导出与升级

进入「设置 → 导入 / 导出」，点击「选择 JSON 文件」。选定后显示文件名。也可点击「粘贴 JSON」，粘贴备份内容并读取。

导入文件后先显示词库、条件规则和保护词数量，再选择追加分类或恢复完整配置。追加可选择内容类型；恢复完整配置前会下载当前备份。

可导出完整配置、某类内容或单个分类。指定分类的保护词会连同对应分类导出，便于恢复关联关系。

1.2.7 使用备份格式 v4，并支持 v1～v3。升级时整理已有分类启停，迁入删句规则和保护词。升级前配置保存在 ST 设置中，可从「设置 → 数据与工具」导出。`1.2.10` 起不再维护多候选替换：旧备份里的 `alternatives` / `multiple` 字段会被忽略，当前 `to` 仍按原样生效。

## 接口与开发

浏览器控制台可调用：

```js
STWordReplacer.open();
STWordReplacer.preview('单车驶来。');
STWordReplacer.export();
STWordReplacer.upsert({ category: '日常用词', from: '单车', to: '自行车' });
STWordReplacer.import(backup);
```

开发环境使用 Node.js 20+，运行 `npm test`。扩展使用原生 ES 模块，安装时直接加载仓库文件。

## 精确保护与优先级

保护词按命中的文字保留。删句范围覆盖保护词时，保留该词，其余命中内容继续清理。保护词内部的关键词会跳过触发。替换范围与保护词重叠时，保留该次匹配。

「设置 → 保护《书名》」识别同一行内成对的《……》，覆盖书名内部的关键词；此选项单独保存。

条件规则编辑器的「进阶：保护优先级」可选择保护优先或清理优先。清理优先适用于需要覆盖保护词、书名及代码范围的特定清理规则。语境模板继续遵守保护。

通过伴随词可以区分触发条件与清理目标：填写要清理的关键词，再在补充条件中填写同句伴随词，删除范围由目标关键词决定。测试效果按完整配置运行，显示最终结果。
