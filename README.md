# 词汇快捷替换

SillyTavern 前端扩展，用于整理词汇、清理句子和保留指定内容。安装后从扩展设置或聊天输入区的魔法棒打开。

当前版本：**1.2.1 · 开发测试版**。

## 安装与更新

在 SillyTavern 的「扩展 → 安装扩展」中填写：

```
https://github.com/kyoya0307/ST-WordReplacer
```

安装完成后刷新页面。后续在「管理扩展」中更新，再刷新页面。

仓库根目录包含扩展入口，SillyTavern 直接克隆仓库加载。安装时使用运行 SillyTavern 那台设备的 Git 和网络；遇到网络错误，可检查该设备的代理、Git 配置和服务端日志。

## 从这里开始

主导航依次为五页：

| 页面 | 用途 |
| --- | --- |
| 词库 | 固定文字的替换与直接删除 |
| 条件规则 | 固定结构、关键词删句、标记内容和语境处理 |
| 冲突检查 | 检查已启用内容中的不同处理结果 |
| 保护词 | 集中整理需要保持原样的文字 |
| 设置 | 作用范围、生效方式和数据工具 |

新安装提供空白分类。可以添加第一条词，也可以通过「设置 → 导入 / 导出」加载备份。「设置 → 可选词库与维护工具」提供基础词库预设。

每次打开进入词库，保留上次查看的分类。电脑左侧选择分类；手机点击当前分类名称，打开可搜索的分类面板。

## 词库

词库页顶部直接提供「原词 → 替换为」输入框。填写后点击「添加」或按回车，保存后输入框清空并定位到原词，方便连续录入：

- **替换为**：填写新的文字，例如 `单车 → 自行车`。
- **删除文字**：替换词留空，删除命中的固定文字，例如 `今天【待删】出发。 → 今天出发。`。

点击已有词条进入编辑。编辑框内保存后应用；各类开关、排序和保护词修改自动保存。

批量添加每行一条，支持箭头、`=>` 或制表符：

```text
单车 → 自行车
【待删】 →
```

普通词条按完整文字匹配。长词优先；相同原词以靠后的已启用分类为准。替换结果在本轮词库匹配中处理一次。

分类设置提供改名、上下排序和单类导出。批量选择后可复制、剪切、启停；切换目标分类后粘贴。剪切在成功粘贴后移除来源条目。粘贴预览提供新增、相同和冲突数量。

选择直接删除的词条，点击「移到条件规则」，可以设定删除范围并迁入规则分类。

## 分类开关

分类复选框汇总条目的实际状态：

- 勾选：全部启用。
- 横杠：部分启用，同时显示启用数量。
- 空框：全部停用。

勾选整个分类会启用所有条目；取消勾选会停用所有条目。在停用分类中单独开启一条，该条立即生效，分类显示部分启用。

顶部总开关用于暂停全部处理，并保留分类选择。

## 条件规则

每条规则按「匹配条件 → 处理方式 → 查看效果」编辑。右侧或下方展示测试原文、命中位置和处理结果。

| 条件 | 示例 |
| --- | --- |
| 关键词 | 出现 `【待删】` 时删除所在分句 |
| 共同出现 | 同一句包含 `声音` 和 `平`，顺序任意 |
| 固定结构 | `极` ＋ `1 个汉字` ＋ `的` |
| 起止标记 | `[示例开始]` 与 `[示例结束]` 之间的内容，包含标记 |

固定结构可以设置中间汉字的最少、最多字数。例如：

```text
处理前：响起极轻的脚步声，随后传来极重的撞击声。
处理后：响起脚步声，随后传来撞击声。
```

起止标记支持跨行，逐段匹配成对标记。示例用于填入编辑器，保存后启用。

### 删除范围

- **匹配文字**：只处理匹配到的片段。
- **所在分句**：按逗号分隔，删除命中分句并整理相邻标点。
- **完整句子**：从句首处理到句末，包括句末标点。

分类可设定默认范围，单条规则可沿用分类或自行选择。关键词共同出现时，分句范围覆盖这些关键词所在的连续分句。句号、问号、感叹号、分号、省略号及换行构成句子边界。

| 原文 | 删除分句后的结果 |
| --- | --- |
| `她点头，【待删】这句是草稿。` | `她点头。` |
| `她点头，【待删】这句是草稿，然后坐下。` | `她点头，然后坐下。` |

规则卡片直接显示触发词、固定结构、起止标记和补充条件。语境模板直接显示其匹配内容，固定替换规则显示实际替换文字。点击「编辑 / 测试」修改配置并试用。搜索支持规则名称及具体触发内容。

多个删除范围合并后整理标点；重叠替换采用最长匹配，同长度采用靠后的规则。句段和固定结构先处理；语境模板沿用其词库前、词库后的执行位置。

### 补充匹配条件

编辑器中的「补充匹配条件」可逐项添加前接、后接、伴随词和保留条件，每项配有成对示例：

| 条件 | 示例：苹果 → 水果 |
| --- | --- |
| 前接“红”时处理 | 红苹果 → 红水果；青苹果保持原样 |
| 后接“汁”时处理 | 苹果汁 → 水果汁；苹果树保持原样 |
| 后接“公司”时保留 | 苹果公司保持原样；桌上有苹果 → 桌上有水果 |
| 同句含“品牌”时保留 | 这个品牌叫苹果。保持原样；桌上有苹果。可以命中 |

文字边界可选择任意位置、两侧为非汉字边界，或两侧为标点、空白及文本边缘。例如“草稿。”满足独立边界；“草稿纸”与其他汉字相连。

伴随词和保留词可在同一句或同一逗号分句内判断。共同出现规则可设置关键词的最大间隔，0 表示不限。试用结果会显示处理次数和保留原因，帮助核对每项条件。

### 语境模板与旧规则

旧版 7 类、13 个匹配步骤整理为普通规则卡片，归入「语境规则」分类。分类与条目开关、固定替换文字和词库前后执行位置继续保留。新安装可从「语境模板与共享保护表」添加这些模板，也可在新建规则时选择「语境模板」。

每张语境卡片提供「旧规则检查」，说明已发现的匹配问题。亲属类模板优先保留可能的所属结构；独立表达使用完整汉字边界；名称类模板提供汉字连写保护。这些策略可逐条选择，补充条件继续适用。

名词和动作保护表集中在「语境模板与共享保护表」中编辑。旧备份中的自定义边界规则继续沿用其起止标点，在统一编辑器中查看。

## 保护词

创建保护词分类，每行一条批量添加，或逐条录入。默认保护范围为全部处理，也可选择指定词库、规则分类或内置语境处理。

例如将 `晨光计划` 加入保护词，该短语保持原样。普通替换保留匹配到的保护内容；分句和整句规则在涉及保护内容时保留对应句段。条件规则的「范围与保护」可单独选择是否遵守保护。

## 测试与冲突检查

词库、条件规则和保护词页顶部提供「测试效果」。「冲突检查」位于主导航中，在条件规则与保护词之间；「导入 / 导出」集中放在设置中。

测试可使用全部已启用内容或当前分类，可载入最近 AI 回复。匹配位置使用划线标记，详情显示命中来源及按条件保留的原因。在测试中选中文字或手动填写，可以直接加入全局保护并重新测试。

冲突检查仅列出已启用内容中的不同处理结果。相同原词对应不同结果、相同条件采用不同处理时，显示来源并提供定位入口。完全相同的重复项作为普通重复保留。

## 生效与保存

默认作用于 AI 输出，影响显示和模型输入，编辑后生效，并保护代码块。设置中可分别调整。

自动处理保留聊天文件原文，显示内容和模型请求副本使用处理结果。新版原生格式化接口在 Markdown 前处理；兼容显示就地更新可读正文，保留 HTML 标签、交互元素和 iframe。兼容显示中的代码保护保持代码节点原样，iframe 内部独立运行。

配置保存在当前 ST 用户的扩展设置中。更新扩展后继续使用已保存的配置。

## 导入、导出与升级

导入文件后先显示词库、条件规则和保护词数量，再选择追加分类或恢复完整配置。追加可选择内容类型；恢复完整配置前会下载当前备份。

可导出完整配置、某类内容或单个分类。指定分类的保护词会连同对应分类导出，便于恢复关联关系。

1.2.1 使用备份格式 v4，并支持 v1～v3。升级时整理已有分类启停，迁入删句规则和保护词。升级前配置保存在 ST 设置中，可从维护工具导出。

「永久处理历史消息」收在维护工具中。它会预览、下载原文备份，再按确认结果改写当前聊天，并提供本次会话撤销。

## 接口与开发

浏览器控制台可调用：

```js
STWordReplacer.open();
STWordReplacer.preview('单车驶来。');
STWordReplacer.export();
STWordReplacer.upsert({ category: '日常用词', from: '单车', to: '自行车' });
STWordReplacer.import(backup);
```

开发环境使用 Node.js 20+，运行 `npm test`。扩展使用原生 ES 模块，安装时直接加载仓库文件。
