# 词汇快捷替换（ST-WordReplacer）

SillyTavern 独立前端扩展：分类词库、跨分类批量复制与剪切、特殊句式管理、全库检索与冲突检查、保护词、替换预览和 JSON 备份。不需要酒馆助手，不需要构建或安装 npm 依赖。v1.1.0 起自动替换保留聊天文件原文。

## 安装

1. 在 SillyTavern 中打开「扩展」→「安装扩展」。
2. 填入 `https://github.com/kyoya0307/ST-WordReplacer` 并安装。
3. 刷新 ST 页面，在「扩展设置 → 词汇快捷替换」中点「打开词库管理」，或从输入区旁的魔法棒菜单点同名条目。
4. 如果同时使用其他文本替换脚本或扩展，请检查它们的作用范围，避免重复处理。

如果手动安装，把本仓库文件放入 `SillyTavern/data/<你的用户目录>/extensions/ST-WordReplacer/`；`manifest.json` 必须直接位于这个文件夹中。也可放在 `SillyTavern/public/scripts/extensions/third-party/ST-WordReplacer/` 供所有用户使用。刷新页面后加载。

## 快捷入口

- 顶部扩展设置中的「词汇快捷替换」折叠面板。使用 ST 内置扩展的标题结构，方便扩展菜单整理工具识别。
- 聊天输入区旁的魔法棒菜单中的「词汇快捷替换」。
- 在聊天正文中选中不超过 200 字的文本，点击右下角「＋ 加入词库」，自动填入新增原词。

## 界面与日常操作

每次打开都进入「词库」页，并退出批量选择模式。桌面左侧切换分类；手机顶部使用分类下拉框，词条以卡片显示。

主导航为「词库 / 句式 / 冲突 / 设置」。默认页面保留总开关、查找和编辑；词库页顶部直接提供「导入词库」和「导出备份」按钮，电脑和手机都会显示。当前分类旁直接提供「↑ 上移」「↓ 下移」排序按钮。作用范围、详细备份选项和历史处理收在「设置」。分类改名、开关、导出与删除在「分类设置」中。

普通状态不显示词条选择框和批量操作栏。点击「批量选择」后，底部出现全选、复制、剪切和粘贴等操作；点击「完成选择」收起。切换分类时可以继续粘贴，切换主页面或重新打开窗口则退出选择模式。退出选择不会删除词条。

「词库 → 试用与保护词」可就地预览替换结果、编辑保护词；展开后修改词条会同步更新预览。词条修改自动保存；句式页的编辑区提供即时试用，点击「保存并启用」或「保存修改」后才应用。

## 配色

点击窗口右上角的 **☼ 配色按钮**，每次切换一种配色，依次循环 **跟随 ST → 粉色 → 绿色 → 米色 → 黑色 → 白色 → 跟随 ST**，无需打开下拉菜单。默认跟随 ST；右侧的 **×** 用于关闭窗口。操作栏滚动时保持可见。切换配色立即生效，关闭窗口或刷新页面后保留选择；不会清空正在编辑的内容。按钮提示显示当前配色和下一种配色，也支持聚焦后按 Enter 或空格切换。

v1.1.5 起，固定浅色主题采用较低亮度、较低饱和度的灰粉、灰绿、米灰和灰白底色，黑色主题减轻亮字与深色背景的强反差。「跟随 ST」仍使用宿主配色。

固定配色仅作用于本扩展的管理窗口，不改变 SillyTavern 其他界面。配色随设置备份；追加导入词库保留当前配色，覆盖全部设置时恢复备份中的配色。旧备份没有配色字段时默认跟随 ST。

## 分类词库

扩展内置 124 条词条，分为「删除词」「整词替换」「单字替换（注意误替换）」，并提供空白的「自定义词库」分类。内置词库面向特定用词偏好，安装后可先查看、修改或关闭相关分类，再按自己的需要使用。特殊句式规则提供独立开关。

可以新建、改名、开关、删除和调整分类顺序。每条词也能开关、直接修改。修改后会自动写入 ST 的扩展设置，随 ST 用户设置保存在服务器；升级扩展不会用默认词库覆盖你的设置。不会自动提交到 GitHub，也不会共享给其他 ST 用户。建议定期导出备份。

选中分类后点击 **「↑ 上移」「↓ 下移」**，每次移动一位，旁边显示当前位置；第一个分类不能再上移，最后一个分类不能再下移。排序自动保存，并随备份导出。排序也决定同名词的优先级：**靠下的已启用分类生效**；长词优先规则不受影响。

在「词库」页上方填写 **原词 → 替换词**，点击「添加 / 更新」。同分类中存在相同原词时更新该词；替换词留空默认只删除原词。支持搜索、每页 80 条，便于较大词库编辑。

在「分类设置 → 本分类空替换值的删除范围」中，也可选择「删除命中的连续分句」或「删除完整句子」。只影响该分类中替换值为空的词条，非空替换照常工作；旧分类默认保留原行为。这类删除先于普通词库替换，受分类和词条开关控制，不依赖「启用特殊句式」。复制、剪切词条到另一分类后，空替换值使用目标分类的删除范围。

「批量添加到当前分类」支持每行一条：

```text
# 这是注释
旧称 → 新称
【草稿标记】 →
早上好 => 你好
```

也支持制表符分隔；批量粘贴会去掉原词与替换词两端空格。需要匹配空格时，请用单条编辑。

## 跨分类复制、剪切与检索

先点击「批量选择」，再勾选词条的「选择」（和「启用」独立），或点击「全选搜索结果」选择当前搜索结果的全部页。点击「复制所选」，切换目标分类，再点击「粘贴到此类」。复制内容保存在扩展内部，手机上也不需要系统剪贴板权限，刷新页面后清空。复制保留替换词、换行和单条启用状态。

粘贴前会显示新增、重复、冲突数量：完全相同的词条直接跳过；同原词的替换配置不同时，默认保留目标分类现有词条。也可选择覆盖现有替换配置，或将冲突项作为停用词条新增，核对后再启用。覆盖会采用复制项的替换配置，但保留目标词条原有的启停状态。点击「确认粘贴」才应用。

需要移动词条时，点击「剪切所选」，再切换到另一个分类粘贴。剪切只标记待移动项，**粘贴成功后才移除源词条**。取消粘贴、清空剪贴内容或刷新页面都不会删除源词条。遇到被跳过的冲突或启停状态不一致时，相应词条保留在源分类；已修改、已删除的源词条会使本次移动停止，需重新剪切。目标中已有文字、替换配置和单条开关完全相同的词条时，确认粘贴可移除源分类中的重复项。移动后是否生效还取决于目标分类的总开关。

每个分类都有原词/替换词搜索。「冲突」**只列出冲突词条**，可以在冲突中搜索分类名、原词、替换词，并定位回分类。没有冲突时显示「没有发现冲突」；有冲突但搜索未匹配时会提示清空搜索。

- 同原词、同当前替换值且删除范围相同：属于相同重复，不列入全库冲突结果；分类内仅作提示。
- 同原词、不同当前替换值，或空值的删除范围不同：冲突警告，显示来源分类、删除范围和当前实际生效规则。
- 仅检查同时启用的分类和词条。停用分类或停用词条不参与检查；两个版本只启用其中一个时，不显示冲突，也不显示“潜在冲突”。冲突页、词条标记和预览提示使用同一判断。
- 长词包含短词不算同名冲突，按长词优先处理。此检查不是对所有上下文正则的语义验证。

## 句式：先选例子，再填词

打开「句式」，先看到「我的删除规则」和三个可点选的示例。无需了解正则，也不用填写起止标点：

| 示例 | 关键词 | 处理前 | 处理后 |
| --- | --- | --- | --- |
| 含某个词就删 | 草稿标记 | 她点头，草稿标记出现在这里。 | 她点头。 |
| 两个词同句出现 | 声音、平（分别填一行） | 她点头，声音传来，语调平静。 | 她点头。 |
| 命中就删整句 | 重复说明 | 她进门，重复说明了一遍。她坐下。 | 她坐下。 |

1. **点一个示例或「＋ 新增规则」**：示例只填入编辑区，不会立即启用。
2. **遇到哪些词**：每行填一个普通词。选择「任意一个词出现就触发」，或「所有词在同一句出现才触发」。
3. **删除多少**：选择只删逗号隔开的命中分句，或连整句话一起删除。
4. **先试一句**：直接输入测试文字，或点「生成测试句」。划线部分是实际要删除的文字和标点，下方显示处理结果。此处只试当前规则，不受普通词库干扰。
5. **保存**：点击「保存并启用」或「保存修改」。取消编辑不改变已有配置。保存后仍需开启总开关和「启用特殊句式」才用于聊天。

已有规则以卡片显示关键词、触发条件和删除范围，可直接开关；点击「编辑 / 试用」才展开表单。规则名称、保护开关收在编辑区的「更多设置」中。默认遵守保护词及代码块保护；取消勾选后即使命中这些内容也会删除。「声音＋平」示例使用后一种设置。

### 同一句有多个关键词时

「所有词在同一句出现」不限制顺序、间隔或出现次数，也不判断语义。选择删分句时，按所有命中位置，删除最早和最晚命中所在分句，以及中间的连续内容。例如：

```text
关键词：声音、平
处理前：她点头，声音传来，中间的描述，语调平静，随后离开。
处理后：她点头，随后离开。
```

只有“声音”或只有“平”不触发；“声音传来。房间平静。”分属两句话，不触发。需要只含一个词就删除时，选择「任意一个词出现就触发」；它只删各自命中的分句，不连带中间未命中的分句。

### 标点如何衔接

逗号（中英文）划分分句；句号、问号、感叹号、分号、省略号和换行划分句子。冒号不单独划分分句，英文点号也会分句。

| 删除位置 | 处理前 | 处理后 |
| --- | --- | --- |
| 句首 | 草稿标记，后文。 | 后文。 |
| 中间 | 前文，草稿标记，后文。 | 前文，后文。 |
| 句尾 | 前文，草稿标记。 | 前文。 |
| 全句 | 草稿标记。 | 整句删除，包含句末标点 |

删末尾分句时一并删除前面的逗号，保留句末标点，避免留下“，。”。多条删除规则先合并命中分句，再处理标点。没有结束标点时处理到文本末尾；换行保留，剩余文字的配对引号和括号保留。

「用一段话检查全部规则」可以粘贴段落或载入最新 AI 回复，查看已保存的句式、分类删除和普通替换共同运行的结果。自动处理仍保留聊天文件原文。

### 内置句式与旧版边界（进阶）

原有 13 个匹配步骤仍分为 7 组，收在「内置句式与保护设置（进阶）」中，一般无需调整。展开后可查看用途、试用文本、保护条件，逐组开关或更改固定替换文字；固定替换值为空表示删除匹配片段，不是删除整句。名词与动作保护表继续保留。

旧版自定义起止标点规则收在「旧版边界规则」中，保留原来的行为，不自动迁移为新版分句模板。日常新增规则推荐用上面的三个示例。局部保护只约束对应规则，其他普通词库仍可能继续处理；请用「全部规则」预览核对实际效果。

普通词条和模板的输入框都接收**纯文本**，不执行正则表达式；`$1` 等内容按普通文字处理。

## 旧版候选配置兼容

v1.1.3 起移除候选编辑与切换界面，所有词条统一使用「原词 → 替换为」。旧版词条继续使用原来选中的替换值，空值仍表示删除。已有备用数据随备份和复制保留，但不在界面展示，也不参与搜索；修改替换词会更新当前生效值。可以分别导出不同分类或配置供他人选择。

## 推荐配置与原文保护

在「设置 → 作用范围」中，默认只勾选「AI 输出」，其他消息范围可选。默认开启「编辑后生效」「影响显示」「影响模型输入」「保护代码块」。点击「应用推荐配置」恢复这些开关，不更改词库。

| 显示 | 模型输入 | 效果 |
| --- | --- | --- |
| 开 | 开 | 你看到的正文和普通聊天生成时发送给模型的历史都替换 |
| 开 | 关 | 仅改变显示 |
| 关 | 开 | 仅改变发送给模型的历史 |
| 关 | 关 | 自动处理暂停，可继续预览和管理词库 |

**上述四种组合都不改写聊天文件原文。** 作用范围目前提供 AI 正文和自己的消息；不会添加或改写 ST 原生正则，世界书、系统提示词、快捷命令源码和独立推理区不作为本扩展的替换范围。

v1.1.6 起，在支持 `messageFormatter` 的 ST 中，通过正式的显示格式化接口，在 Markdown 转换和前端界面渲染之前处理正文。加载聊天、生成回复、切换 swipe 时由 ST 正常渲染，不再在消息渲染完成后重画整条消息，避免把交互界面覆盖回代码块。显示结果不写回聊天数据。

修改词库后，普通消息会按需刷新；没有变化的消息不重复刷新。**含 HTML 或交互界面的消息保留当前界面，重新进入聊天时应用新配置**，包括关闭替换后的显示恢复。代码块是否参与替换仍由「保护代码块」和各句式的保护选项控制。

旧版 ST 若没有这一接口，会采用兼容方式处理普通消息，并跳过含 HTML 或交互界面消息的显示替换；建议更新 ST 后使用。设置页会显示当前适用的说明。

模型输入仍通过 ST 的普通聊天生成 interceptor 处理生成请求中的历史副本，推理前缀保留。不会影响输入法。其他扩展自行发起、绕过 ST 普通聊天生成流程的请求不保证接入。

编辑消息时 ST 展示原文，保存编辑后默认显示替换结果。「编辑后生效」关闭时不主动处理本次编辑后的显示；之后重新加载聊天或发送模型输入时仍按对应开关处理。词库改动不改写原文。

升级会保留已有分类和词条，旧版配置自动迁移到保留原文模式，并默认开启编辑后生效。旧版本曾经永久改写的文本不会自动恢复；新版从当前保存的文本开始处理。

## 匹配顺序

1. 先按原文计算分类删除和已启用的句式模板的删除范围，合并后处理标点。分类删除遵守保护词和代码块保护；模板可在「更多设置」选择是否遵守保护。
2. 其余文字中的保护词和代码块原样保留。
3. 如开启特殊句式，执行内置的前置上下文规则。
4. 已启用分类中的已启用词条按**长词优先**匹配；相同原词由**靠后的分类**覆盖。同分类重复原词以靠后的词条为准。
5. 一次词库替换不会把结果再次送回词库匹配，例如 A→B、B→C，原文 A 只会变为 B。
6. 如开启特殊句式，再执行内置的后置上下文规则。

例如同时设置“嫁 → 娶”和“嫁给我 → 和我结婚”，出现“嫁给我”时使用整句规则，单独出现“嫁”时使用单字规则。改变分类顺序不会改变长词优先；分类顺序只决定相同原词的覆盖关系。

自定义词条是**纯文本**，不是正则表达式。`$&` 等内容也按普通替换文本处理。特殊句式规则在词库前后执行；如果只想使用分类词库，可关闭「启用特殊句式」；分类自身的空值删句设置仍然生效。

单字规则和上下文规则可能影响名字、普通词语或链接；请在「词库 → 试用与保护词」测试、添加保护词，或关闭相关分类。

## 备份与历史消息

在默认打开的「词库」页顶部点击 **「导入词库」**，按页面上的三个步骤操作：

1. 点击「选择 JSON 文件」，选择本扩展导出的词库文件，页面会显示文件名。
2. 选择导入方式：「追加为新分类」仅追加分类和保护词；「用备份覆盖全部设置」会同时恢复句式、配色和开关。
3. 点击「导入 JSON」。成功后会显示分类和词条数量，点击「查看词库」即可返回编辑。格式错误会在导入按钮附近显示原因，原有词库保留。

词库页顶部的「导出备份」可保存全部设置；单个分类在「分类设置」中导出。「设置 → 备份与导入」仍可使用。只接收本扩展的 JSON 数据，不执行 JS。其他格式词库可先整理为批量文本粘贴。

备份包含特殊句式的开关、固定替换文字、保护表和句段删除规则。追加导入保留当前特殊句式与句段规则，只合并分类和全局保护词；选择覆盖全部设置时才恢复备份中的这些配置。旧备份缺少相关字段时使用默认内置规则，句段规则默认空列表。

v1.1.4 使用备份格式 `version: 3`，保留模板条件和分类删除范围，并兼容导入旧版 v1/v2 备份。新备份需要 v1.1.4 或更新版本；请先更新扩展再导入。升级扩展不会自动添加示例规则或更改现有分类的删除范围。

可以将导出的 JSON 文件作为词库配置分享，接收者在「设置 → 备份与导入」中导入即可。当前版本尚未提供多个预设配置的选择菜单。

「设置 → 历史消息」是单独的**手动永久改写工具**，和日常自动替换不同：它先预览当前聊天，再确认改写聊天文件原文。日常使用无需操作此页。默认仅处理 AI 正文，可选择同时处理自己的消息。应用前下载受影响消息的原文 JSON 备份，并提供本次页面会话中的撤销按钮。期间若切换聊天、修改消息或修改词库，必须重新预览。请确认浏览器允许下载备份。下载文件是**正文备份记录**，不是完整的 ST 聊天导入文件；需要完整聊天备份时请先使用 ST 自带的聊天导出。

历史撤销只在当前页面和当前聊天有效；刷新或切换聊天后，请从下载的原文记录手动恢复。

## 快捷编程接口（可选）

扩展加载后提供 `window.STWordReplacer`，方便你从其他脚本或浏览器控制台管理词库。接口操作仍只保存到 ST 设置。

```js
STWordReplacer.open();
STWordReplacer.upsert({ category: '用词习惯', from: '旧称', to: '新称' });
STWordReplacer.upsert({ category: '删除词', from: '【草稿标记】', to: '' });
STWordReplacer.preview('只预览，不改聊天'); // { text, hits }
const backup = STWordReplacer.export(); // 返回副本
// STWordReplacer.import(backup); // 校验后覆盖当前设置
```

## 更新与开发

在 ST 扩展管理器中手动检查/更新本扩展，然后刷新页面。没有后台自动下载或外部脚本依赖。

### 安装与网络排查

仓库根目录直接包含 `manifest.json`、`index.js` 等文件，无需额外打包或 npm 构建。ST 安装器会在运行 SillyTavern 的设备上克隆 Git 仓库，再读取根目录的 manifest。该设备上的 Git 需要能够访问 GitHub；浏览器能打开网页不能代替这一步。出现网络错误时，请查看 SillyTavern 服务端日志，并检查运行设备的网络连接、代理和 Git 配置。

如果安装成功但显示旧版入口，请在「管理扩展」中更新本扩展并刷新。v1.0.1 增加魔法棒入口，修正设置区原生标题结构，并移除键盘快捷键和输入框额外按钮。手动 ZIP 安装没有 Git 元数据，无法直接通过 Git 拉取更新，需要之后再次手动更新。

开发测试：Node.js 20+，运行 `npm test`，无须 `npm install`。使用 ST 官方 `SillyTavern.getContext()` 获取设置、事件、正文更新和聊天保存接口。

参考：[ST 扩展开发文档](https://docs.sillytavern.app/for-contributors/writing-extensions/)、[ST release 源码](https://github.com/SillyTavern/SillyTavern/tree/release/public)。
